# JTGEATS

JTGEATS is a food delivery platform designed to provide a seamless and efficient experience for users to browse, order, and receive food from their favorite restaurants.

## Features
- User-friendly interface for browsing restaurants and menus
- Cart and checkout functionality
- Responsive design for mobile and desktop

## Tech Stack
- HTML, CSS and JavaScript
